# Prévia da loja Playtime

Cópia de segurança da prévia navegável publicada como artefato no claude.ai
(https://claude.ai/artifact/RhyQz9ALFiwDwAm8SGY1Wc), recuperada em 09/11/2026.

- `index.html` — página da prévia (HTML, CSS e JS do tema)
- `logo-dourado.svg`, `emblema.svg` — marca
- `frames/` — quadros da animação do topo (hero_ = computador, hero-m_ = celular)
- `videos/` — vídeos em loop da Clínica e do Passaporte, com capas

Os arquivos do tema Shopify (.liquid) serão reconstruídos a partir desta prévia.
